# Universal-Hall

> 本科毕业设计 · 基于 D3D12 延迟渲染管线的参数化写实风格切换系统

---

## 1. 项目概述

### 1.1 研究背景

在写实风格渲染的传统工作流中，画面风格通常与资产数据深度耦合：贴图、材质、灯光参数均固化在场景资源内。若需调整画面风格，须重新编辑并烘焙资产，迭代周期长、成本高，且难以在同一场景下对多种风格方案进行快速对比。

### 1.2 研究目标

本项目旨在将"风格"从资产层中剥离，抽象为一组可在运行时热加载的参数集合，使风格切换退化为加载一个 JSON 配置文件的过程。具体目标为：

- 构建一条基于 DirectX 12 的延迟渲染管线；
- 设计参数化风格层，将光源、材质、后处理等风格相关参数集中管理；
- 接入 NVIDIA DLSS 5 超分辨率与重建链路，在降低内部渲染分辨率的同时维持输出画质；
- 实现预设的运行时热切换，切换过程不触发管线状态对象（PSO）重建、不重载资源。

### 1.3 交付物

本项目以可运行的演示程序为核心交付物，辅以对照截图与演示录像，用以验证参数化风格切换的可行性与效果。

## 2. 系统设计

### 2.1 管线架构

系统采用延迟渲染管线，主要分为以下阶段：

1. **几何阶段**：将场景几何体渲染至 GBuffer；
2. **GBuffer 阶段**：输出 Albedo、Normal+Roughness、Depth 等几何/材质信息；
3. **光照阶段**：基于 GBuffer 执行延迟光照计算；
4. **后处理阶段**：色调映射、曝光补偿、LUT 校色等；
5. **超分/重建阶段**：通过 DLSS 进行超分辨率、帧生成与神经重建。

### 2.2 参数化风格层

风格相关参数以 JSON 预设形式组织，由 PresetManager 统一加载与切换。参数类别包括：

| 参数类别 | 说明 |
|---------|------|
| Albedo 映射 | 同一几何体切换不同贴图集 |
| Roughness 覆写 | 全局乘数与钳制下限 |
| 光源参数 | 色温、强度、方向 |
| 后处理参数 | 曝光补偿、色查表 LUT |
| 神经重建参数 | Structure / Tone 强度（条件性） |
| 渲染控制参数 | 内部缩放比、SR/NR/FG 开关、NR 执行顺序 |

**核心约束**：预设切换为纯参数变更，不得触发 PSO 重建或资源重载，以保证切换的即时性与一致性。

### 2.3 DLSS 链路

通过 NVIDIA Streamline 接入 DLSS 5，支持以下特性：

- **DLSS-SR**：超分辨率，内部渲染分辨率低于输出分辨率；
- **DLSS-FG**：帧生成，通过插帧提升帧率；
- **DLSS-NR**：神经重建（条件性实现，若受硬件或驱动限制无法运行，则在论文中如实声明为预留接口）。

内部缩放比支持多档可调，用于对比不同分辨率下的画质表现。

### 2.4 对比验证机制

系统提供 AB 分屏对比模式，在同一机位、同一几何、同一 shader 条件下，左右分屏展示不同预设的渲染结果，以直观验证风格切换的效果。

## 3. 技术栈

| 模块 | 技术选型 |
|------|---------|
| 图形 API | DirectX 12（Agility SDK） |
| 渲染管线 | 延迟渲染（Deferred Rendering） |
| GBuffer | Albedo / Normal+Roughness / Depth |
| 阴影 | 级联阴影映射（CSM） |
| 超分/重建 | NVIDIA DLSS 5（SR + FG + NR）via Streamline |
| 用户界面 | ImGui |
| 场景 | 程序化生成的室内场景 |
| 参数管理 | JSON 热加载 + PresetManager |

## 4. 项目结构

```
Universal-Hall/
├── src/
│   ├── Core/               # D3D12 设备、交换链、命令队列
│   ├── Rendering/

│   │   └── presets/        # 风格预设 JSON 文件
│   ├── UI/                 # ImGui 面板
│   └── main.cpp
├── assets/                 # 场景资源、LUT 等
└── README.md
```

## 5. 实现计划

按优先级分为三个阶段，P0 阶段完成即可构成完整可答辩的毕设成果。

| 优先级 | 内容 | 说明 |
|--------|------|------|
| **P0** | D3D12 设备 + 交换链 + 基础几何 | 跑通 Agility SDK |
| **P0** | GBuffer + 全屏四边形回读 | 验证缓冲数据正确性 |
| **P0** | 延迟光照 + 色调映射 + 室内场景 | 产出可用画面 |
| **P0** | PresetManager + ImGui 面板 + JSON 热切换 | 核心功能 |
| P1 | CSM 阴影 | 提升画面质感 |
| P1 | DLSS-SR + FG | 接入 Streamline，支持开关与对比 |
| P2 | Motion Vector | 为 SR/FG 提供运动数据 |
| P2 | DLSS-NR | 条件性实现 |

## 6. 环境与构建

### 6.1 环境要求

- Windows 10 / 11
- Visual Studio 2022（C++ 桌面开发工作负载）
- Windows SDK 10.0.19041 及以上
- NVIDIA RTX 系列显卡及支持 DLSS 5 的驱动程序
- DirectX Agility SDK

### 6.2 构建与运行

```bash
git clone https://github.com/AaronSwartz0217/Universal-Hall.git
cd Universal-Hall
msbuild Universal-Hall.sln /p:Configuration=Release
```

启动程序后，可通过 ImGui 面板进行预设切换、内部缩放比调节及 AB 对比模式的启用。

## 7. 风险与降级方案

| 风险 | 降级方案 |
|------|---------|
| DLSS-NR 无法稳定运行 | 论文中声明为条件性内容，以"SR+FG 实测 + NR 接口预留"形式呈现 |
| DLSS 整体接入受阻 | 以自实现的 lanczos / bicubic 下采样-上采样作为占位方案，确保参数化切换主线可演示 |

## 8. 论文结构指引

按实现顺序撰写，以对照截图为主要结果呈现形式：

1. **绪论**：阐述风格与资产耦合的问题，提出参数化风格层的思路
2. **相关工作**：DLSS 系列技术、神经渲染、风格化渲染
3. **系统设计**：管线架构、GBuffer 布局、PresetManager 与热切换协议、DLSS 链路接入
4. **实现过程**：设备初始化、GBuffer 搭建、阴影、Streamline 接入（主体章节）
